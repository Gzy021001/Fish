# 移动端单据录入 (Billing Form) 设计规范

## 1. 概述
在移动端支持账单的新增与编辑功能，满足随时随地“记一笔”的需求，并支持高频的连续录入。本功能严禁破坏现有的 PC 端代码，完全在 `src-mobile` 目录下独立开发。

## 2. 交互入口与流程
- **新增入口**：在 `Billing.vue`（账单列表）的右下角增加悬浮按钮（FAB）。
- **编辑入口**：在 `BillingDetail.vue`（账单详情）底部增加“编辑”按钮。
- **页面承载**：新建 `src-mobile/pages/BillingForm.vue` 页面处理新增和编辑逻辑。
- **连续录入（新增模式下）**：保存成功后，提示“保存成功”，清空重量、单价、品种等信息，**但保留所选日期**，并留在当前页面以便连续录入。
- **编辑模式下**：保存成功后，返回详情页。

## 3. 表单字段与布局规范
页面采用标准从上到下的全页表单布局。

### 3.1 字段说明
1. **日期 (release_date)**
   - 使用原生 `<input type="date">`。
   - 新增模式下默认填充“今天”。
2. **品种 (species_id)**
   - 提供支持搜索的下拉列表（可参考 PC 端逻辑，但在移动端需优化触摸面积）。
   - 选中后，**自动将品种的 `default_price` 填入到下面的“单价”输入框中**。
3. **重量 (weight)**
   - 数字输入框（使用 `inputmode="decimal"` 唤起数字键盘）。
4. **单价 (unit_price)**
   - 数字输入框（使用 `inputmode="decimal"` 唤起数字键盘）。
5. **状态 (status)**
   - 提供分段控制器（Segmented Control）或下拉框供用户选择。
   - 选项：待处理（DRAFT）、已完成（COMPLETED）。
   - 默认选中“已完成（COMPLETED）”。

### 3.2 实时计算
- 在单价和重量输入框下方，新增一行显著的 **“小计：¥ xxx.xx”**，其值为 `重量 × 单价`。
- 使用 `computed` 实时响应输入框变化。

### 3.3 保存按钮
- 底部放置宽大的“保存”按钮。
- **校验逻辑**：点击保存时，检查必填项（品种、重量、单价）。若未填，弹出 Toast 提示用户，中断保存。
- 只有所有校验通过才调用后端接口。

## 4. 依赖接口
- **获取品种列表**：`GET /api/species`（用于品种选择器）。
- **获取单据详情**（编辑模式）：`GET /api/bills/{id}`。
- **创建单据**：`POST /api/bills`。
- **更新单据**：`PUT /api/bills/{id}`。

## 5. 组件与状态依赖
- 复用现有的 Toast 提示机制（或 `alert`）。
- 路由使用 `vue-router`，新增 `/billing/new` 和 `/billing/edit/:id` 路由配置。
