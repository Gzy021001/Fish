# 新增品种弹窗优化计划

## 现状分析

当前 [Species.vue](file:///d:/Fish/src/pages/Species.vue#L280-L373) 的"新增品种"弹窗存在以下可改进点：

| 方面     | 现状                         | 问题                                           |
| -------- | ---------------------------- | ---------------------------------------------- |
| 宽度     | `max-w-md`                   | 表单4字段略显局促                              |
| 装饰     | 无装饰元素                   | 项目其他弹窗均有敦煌暗纹/曼陀罗装饰            |
| 标题     | 纯文字 `新增品种`            | 缺少图标或视觉引导                             |
| 品种     | 普通 `<input>`               | 无聚焦态视觉层次                               |
| 单价格式 | 普通 `<input type="number">` | 无 ¥ 符号前缀，与开单页不统一                  |
| 默认单位 | 普通 `<input>`               | 应为下拉选择（斤/公斤/条/只/等）               |
| 图片上传 | 蓝色实心按钮 + 小型预览      | 不符合极简按钮规范；预览太小看不清             |
| 按钮组   | `bg-dunhuang-red` 保存按钮   | 不符合项目极简按钮约定；取消/保存太小          |
| 间距     | `space-y-4` + `p-6`          | 可适当增加留白使呼吸感更好                     |
| 单位预览 | 无                           | 开单页选择品种时会联动显示单位，此处可提前预览 |

## 优化方案

### 1. 弹窗容器升级

- 宽度：`max-w-md` → `max-w-lg`
- 内边距：`p-6` → `p-8`
- 添加曼陀罗装饰元素（参考开单详情弹窗）
- 顶部彩色边框：`border-t-4 border-t-dunhuang-blue`

### 2. 标题栏增强

- 增加品种图标（SVG 小鱼/叶子图标）
- 字体加大：`text-lg` → `text-xl`，保持 `font-serif`
- 下方加柔和分隔线

### 3. 表单字段视觉升级

- **品种**：左侧加标签图标装饰，输入框 `py-3` 加高
- **单价**：左侧固定 ¥ 符号前缀（与开单页一致），右侧步进按钮（-/+）
- **默认单位**：改为 4 个预选单位按钮组（斤 / 公斤 / 条 / 只），替代自由输入，与开单页品种选择卡片风格一致

### 4. 图片上传区域重构

- 采用中央大图预览 + 底部操作区模式
- 预览区：`w-28 h-28` 圆角卡片，显示品种首字或已选图片
- 操作区：极简按钮 "选择图片"（符合项目按钮规范）
- hover 图片显示"点击更换"遮罩层（与 SpeciesDetail 图片上传交互一致）

### 5. 按钮样式统一

- 取消按钮：`text-dunhuang-text/70 hover:bg-dunhuang-yellow/20 border border-dunhuang-yellow/50`
- 保存按钮：保留 `bg-dunhuang-red text-white` 作为主要操作按钮（保存类允许实心）

### 6. 新增单位按钮组数据

- 在 script 中添加 `unitOptions = ['斤', '公斤', '条', '只']`
